01 · Abans de començar

La teoria essencial

El formulari de la pàgina 1, completat amb els apunts de les pàgines 8–11 i 18–19. En els quocients, el denominador sempre ha de ser diferent de zero.

A · Base, exponent i signe

Què s’eleva a la potència?

a^n és el producte de n factors iguals a a, si n és un enter positiu. Amb base fraccionària, s’eleven el numerador i el denominador.

Una base negativa dona resultat positiu amb exponent parell i negatiu amb exponent senar. Els parèntesis decideixen si el signe forma part de la base:

(-3)^2= 9-3^2= −9

Casos especials: a¹ = a; 1ⁿ = 1; a⁰ = 1 si a ≠ 0; 0ⁿ = 0 si n > 0. En aquesta unitat, 0⁰ no està definit.

B · Les propietats del formulari

Tria la regla adequada

Mateixa base: producte
a^m · a^n = a^(m+n)
Mateixa base: quocient
a^m / a^n = a^(m−n)
Potència d’una potència
(a^m)^n = a^(m·n)
Producte i quocient
(a·b)^n = a^n·b^n
(a/b)^n = a^n/b^n

També (a^m/b^n)^p = a^(m·p)/b^(n·p). Les regles es poden aplicar en els dos sentits: amb el mateix exponent pots agrupar les bases.

C · Exponents negatius i simplificació

Inverteix la base, conserva el signe

a^(-n) = 1/a^n(a/b)^(-n) = (b/a)^n

La base ha de ser no nul·la. Un exponent negatiu no vol dir resultat negatiu: 2⁻³ = 1/8, però (−2)⁻³ = −1/8.

Si un factor passa del numerador al denominador, o a l’inrevés, canvia el signe de l’exponent. Per simplificar expressions llargues, descompon les bases: 4 = 2², 8 = 2³, 9 = 3², 27 = 3³, 25 = 5².

Exemple: (4²·2⁻³)/8 = 2⁴⁻³⁻³ = 2⁻² = 1/4. Resol primer les potències interiors i agrupa després.

D · Operacions combinades

Les sumes no segueixen la mateixa regla

Ordre de càlcul: parèntesis → potències → productes i divisions → sumes i restes. Les operacions de la mateixa prioritat es fan d’esquerra a dreta.

La potència d’un producte es pot separar; la d’una suma o resta, en general, no:

(2+3)² = 25però2²+3² = 13

Només es poden cancel·lar factors comuns d’un producte, no termes d’una suma. Escriu un pas per línia per no perdre signes ni parèntesis.

E · Exponents racionals · Pàgina 18

Una fracció a l’exponent és una arrel

Per a a > 0 i n enter positiu:

am/n = ⁿ√(aᵐ) = (ⁿ√a)ᵐ

El denominador n és l’índex de l’arrel; el numerador m és l’exponent. Pots calcular primer l’arrel si és exacta.

Exemple: 82/3 = (³√8)² = 2² = 4. Si l’exponent és negatiu, inverteix: 8−2/3 = 1/4.

Treballarem les conversions i el càlcul amb bases positives com als apunts. No intercanviïs el numerador i el denominador.

F · Radicals · Pàgines 18–19

L’arrel principal i les solucions

L’arrel d’índex n de a és un nombre que elevat a n dona a. Si no hi ha índex escrit, és 2. El coeficient multiplica tota l’arrel.

02 · De la regla al repte

106 exercicis, pas a pas

Comença pels bàsics o activa el repàs prioritari: recull exercicis amb errors, ratllades o correccions als apunts. La dificultat és una orientació. Fes el desenvolupament en paper i comprova aquí el resultat.

Com s’escriuen les respostes?

Fraccions: 3/10. Potències: 2^5 o (2/3)^15. Productes: 2^8*5^5. També s’accepten exponents amb dígits volats, com 2⁵, i decimals amb coma. Conserva els parèntesis de les bases negatives.

Quan es demana una única potència, escriu una base numèrica i un exponent enter: el valor calculat tot sol no basta. En els altres càlculs, dona un enter, una fracció o una expressió de potències equivalent. Els radicals i les conversions tenen opcions per triar.
